# analise-rendimento-escolar-inep
projeto para analisar o abandono e aprovação escolar por UF e rede de ensino, com comparativos de UF e onde a aprovação está mais baixa

## Tecnologias Utilizadas
- **SQL / dbt (Data Build Tool)** para modelagem e transformação de dados.
- **Google BigQuery** como Data Warehouse.
- **Git / GitHub** para versionamento de código.
- **Power BI** para visualização final.
